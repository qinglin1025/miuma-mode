# 牛马模式 · 安卓个人版 0.1.6

面向小米 14 Pro / HyperOS 3 的第一版原生 Android 应用。最低 Android 8，目标 API 35。
当前状态：已通过编译、93 项核心逻辑检查及 APK 签名检查；**尚未在真机启动或验证 HyperOS 行为**。

## 下载安装包

前往 [GitHub Releases](https://github.com/qinglin1025/miuma-mode/releases/latest) 下载 APK。源码仓库不包含个人签名密钥或本地编译工具。

## 安装
1. 将 dist/niuma-mode-0.1.6.apk 传到手机，用文件管理器打开安装。
2. 如果系统提示，允许本次安装来源安装应用。系统的额外检查取决于机型和版本。
3. 打开“牛马模式”，先把倒计时时长设置为 1 分钟，到时动作选择“震动”。
4. 点击“开启牛马模式”，按提示开启悬浮窗权限，再返回应用开启。
5. 允许通知，便于从通知栏退出。进入“权限与小米设置”查看后台弹窗和省电设置说明。
6. 自动锁屏为可选功能：选择后会解释并引导设备管理授权，只申请锁屏权限。

## 使用
- 开启时和每次重新解锁后，默认出现正计时、倒计时、直接息屏、退出四个选项；可在软件内选择任意 2–4 个。
- 正计时从 00:00 开始；圆圈 10 分钟变到最大，之后继续计时。
- 倒计时直接使用应用保存的时长和动作。修改只影响下一次会话。
- 悬浮时钟可拖动，点按可打开退出操作。
- 主动锁屏结束当前会话；再次解锁重新选择。
- 返回桌面仍然计时。“退出牛马模式”才会停止全部悬浮窗、回调及震动。
- 进程被系统清理后不会立即恢复；若启用了每周规则，会在下一次定时时间尝试开启。重启只恢复未来定时，不立即开启模式。强行停止应用后，需要手动打开一次恢复规则。

## 真机验收（待用户测试）
- [ ] 首页正常显示，设置可保存，重新打开仍保留。
- [ ] 开启后正确弹出所选的 2–4 个按钮，倒计时弹窗没有时长设置项。
- [ ] 正计时在其他应用上可见、可拖动，锁屏后消失。
- [ ] 每次解锁只弹出一次选择框；未开启或退出后不弹。
- [ ] 1 分钟倒计时到时震动一次，继续使用不重复震动。
- [ ] 到时提醒显示，点“知道了”关闭。
- [ ] 授权后自动锁屏正常；未授权则显示提醒而不是假装锁屏成功。
- [ ] 倒计时进行中退出，等待原到时时刻，确认不会再震动或锁屏。
- [ ] 小米省电限制下运行至少 15 分钟，检查是否被清理。
- [ ] 正计时 10 分钟尺寸封顶，11 分钟仍继续计时。
- [ ] 横竖屏切换后悬浮球仍在屏幕内。

### 无弹窗或模式停止
在系统应用信息中核对悬浮窗、后台弹出界面等当前系统提供的权限，必要时设置省电“不限制”并锁定最近任务。菜单名称随 HyperOS 版本变化。
不需要 Root；不使用无障碍服务读取其他应用内容。

### 卸载与授权
如果激活了设备管理锁屏授权，系统可能要求先在安全设置的设备管理应用中停用“牛马模式”，再卸载。
设备管理锁屏后，系统可能要求输入密码而非指纹。

## 本地构建
在 Windows PowerShell 7 运行：
    ./setup-tools.ps1
    ./build.ps1
仅运行计时逻辑测试：
    ./build.ps1 -TestOnly

工具来自 Eclipse Adoptium 和 Google 官方下载，下载后核对发布方校验值。
项目不依赖 Gradle 或第三方运行库。首次构建生成本地个人签名密钥。
private/ 内是签名密钥与 Windows 用户加密的口令，**请保留且勿分享**。后续覆盖安装必须沿用此密钥；更换电脑时需另外妥善迁移签名凭据。
源码压缩包不包含工具、编译缓存或签名密钥。
应用无网络权限，配置保存在本机，不上传使用数据。

## 0.1.1 更新：自动锁屏后的选择框恢复
- 在屏幕亮起时检查是否已真正解锁，不再仅依赖 USER_PRESENT 广播。
- 模式运行期间保留每秒一次的屏幕状态检查，倒计时结束后也继续；不持有唤醒锁，不主动唤醒手机。
- 同一会话重复检查不会重复弹窗或重置倒计时，锁屏上不显示选择框，退出后停止检查。
- 这次覆盖了可复现的缺少广播恢复路径；尚无该手机的运行日志，不能断定用户遇到的现象只有这一原因。

更新时直接安装新版 APK，无需卸载旧版；更新完成后重新打开应用并开启模式。
请测试 1 分钟自动锁屏，重新亮屏并完成解锁后，确认三选一弹窗恢复，再连续重复两次。
如果仍不出现，记录当时应用首页是否显示“模式已开启”，以及是仅亮屏还是已进入桌面。

## 0.1.2：直接息屏与自定义弹窗
- 新增“直接息屏”，默认完整顺序为：正计时、倒计时、直接息屏、退出牛马模式。
- 首页“解锁弹窗选项”可勾选任意 2、3 或 4 项，保存后下次弹窗生效，所选项保持上述相对顺序。
- 至少保留两项；只选零项或一项时不能保存。取消修改不影响已保存配置。
- 直接息屏使用与倒计时锁屏相同的授权，未授权时显示引导，不会用黑色遮罩冒充息屏。
- 直接息屏保留牛马模式，下一次解锁重新显示所选按钮。
- 即使隐藏“退出牛马模式”，仍可从应用首页或通知栏退出。
- 默认显示全部四项；升级保留原有倒计时时长和提醒设置。
- 请真机验证各数量组合、设置持久保存、直接息屏后再次解锁，以及未授权时的引导。

## 0.1.3：每周定时开启
首页 → 每周定时开启 → 勾选星期、设置时间、打开启用开关并保存。一条规则支持多选星期，使用手机当前时区。

首次使用需允许系统“闹钟和提醒”及悬浮窗权限；未授权会显示等待状态，不伪装成已经安排。小米还需允许自启动并根据实际情况设置省电“不限制”。通知权限用于后台开启失败提示。

- 默认关闭，不影响旧版手动开启习惯。
- 到点自动启用牛马模式，不强行打开首页，不主动点亮屏幕。
- 如果手机锁着，等你解锁后显示选择框。
- 已经开启时不重复启用、不重置计时。
- 首页显示下次触发时间与上次触发记录；未能后台启动时留下原因。
- 退出模式只结束当前运行，未来定时保留。要取消自动开启，关闭规则并保存。
- 关闭规则仅取消未来定时，不强行终止已在进行的计时。
- 重启、更新应用、时区或系统时间变化后重新安排未来时间。关机错过的时间不补开。
- 为容忍短暂系统延迟，收到闹钟后最多允许晚 5 分钟启动；更晚则跳过并安排下次。
- 无法绕过系统强行停止、关机或厂商拦截，因此仍需目标机实测。

建议测试：选择今天，把时间设为当前时间后 2–3 分钟，保存并确认首页的“下次”时间。退出牛马模式但保留规则，锁屏等待，到点后解锁检查弹窗。然后测试关闭规则不再触发，以及已在计时时不被重置。
