# 牛马模式 · 安卓个人版
目标手机：小米 14 Pro / HyperOS 3.0.309.0.WNBCNXM.C11。
用户已确认此前 UI 和功能并要求继续开发；直接执行，不重复设计审批。

## 行为
用户主动开启前台服务。解锁广播触发三选一悬浮卡片，不在锁屏覆盖。
正计时圆圈从 56dp 渐增至屏幕短边 40%（最多 144dp），10 分钟封顶后继续计时。
倒计时只使用软件内预设，默认 15 分钟、到时震动。应用内可设 1–180 分钟。
到时动作三选一：震动、提醒、自动锁屏；自动锁屏需用户激活设备管理授权。
退出服务取消所有计时、悬浮窗、震动及通知。返回桌面不退出模式。
锁屏结束当前会话；重新解锁重新选择。设置改变影响下一次会话。
无网络权限、账号、远程服务、自启接收器或使用记录上传。

## 实现
Java 原生 Activity + 前台 specialUse Service + WindowManager 悬浮窗。
独立纯 Java Session 驱动状态，elapsedRealtime 为时基；主线程刷新，无精确闹钟需求。
服务 START_NOT_STICKY，意外终止不自动恢复锁屏动作。停止状态以服务存活为准。
设备管理仅声明 force-lock，不申请清除数据等策略。
倒计时完成先消费一次性到时事件，再执行动作；锁屏失败回退可见提醒。
APK 签名密钥保留项目内私有目录；后续更新沿用，不能发送密钥给他人。

## 0.1.2 需求更新
解锁弹窗增加第三项“直接息屏”，退出顺延第四。软件内允许选择显示任意 2–4 项，默认全部显示；隐藏项不占位，相对顺序不变。
直接息屏复用设备管理锁屏授权，保留模式运行；无授权先引导用户，不自动授权。选择数量与时长一样持久保存，下次弹窗生效。
