# 安卓跨品牌验收

0.1.7 使用安卓标准悬浮窗、设备管理锁屏、前台服务和精确闹钟接口。新增功能为通用引导和本地诊断，不代表跨品牌实测通过。

## 当前证据
- 编译、93 项既有逻辑检查、APK 签名及 zipalign 通过。
- 未连接真机或模拟器；新增权限页面、品牌提示、设置回退和剪贴板交互仍待真机验证。
- 支持安装下限 Android 8 / API 26，target API 35。
- 保留原签名支持覆盖安装，无新增系统权限、无网络权限。

## 设备矩阵
小米 / Redmi / POCO、vivo / iQOO、OPPO / realme / 一加、荣耀、可运行 APK 的华为、三星、其他 Android：均待记录具体型号、Android 版本和测试结果。原生鸿蒙与 iOS 不属于此包支持范围。

## 每台设备执行
1. 首次未授权，点击开启，允许悬浮窗并返回；拒绝通知后仍能进入设置补授权。
2. 检查品牌提示、电池优化入口；注意系统豁免不代表厂商自启动或后台运行已允许。
3. 复制设备与权限信息，核对型号、版本和授权状态，不包含账号、序列号、IMEI。
4. 正计时超过 10 分钟，锁屏再解锁，检查圆钟和选择框。
5. 分别验证震动、提醒、授权后自动锁屏；自动锁屏后重新解锁应弹出选择框。
6. 配置 2、3、4 个选项，直接息屏后解锁；无锁屏授权时进入授权引导。
7. 每周规则设为当天数分钟后，验证亮屏、锁屏、已在计时三种状态；关闭开关后不得触发。
8. 重启后验证未来定时恢复；强行停止后手动打开再验证。
9. 后台放置至少 15 分钟；测试系统省电模式、通知关闭和悬浮窗权限撤销。
10. 小屏、大字体、横屏下检查权限列表和弹窗是否可读可操作。

问题反馈：复制设备与权限信息，另附具体操作、预期结果、实际结果及发生时间。
